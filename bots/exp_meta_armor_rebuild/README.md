# Bounded armor maintenance

Parent: `exp_prearmor`, the six-site variant that was neutral over 336 lineage
games and 56% over two 168-game rush runs.

The opening ring, offense, economy, spawning, recall, responder, and siege are
unchanged. The waller remembers only the same six claimed firing-seat sites.
After a verified core threat is published, it heals damaged barriers and
replaces destroyed ones; after turn 60 it never expands to a new site. This is
the replay-observed rebuild loop without a permanent guard or larger ring.

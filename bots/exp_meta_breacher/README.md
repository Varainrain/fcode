# Surgical firing-seat breacher

Parent: frozen `exp_trans_40`.

When direct core plans exist, behavior is identical to v8. Only when no direct
plan exists may Sieger 2 identify a visible enemy barrier that itself occupies a
legal core-firing seat and place a safe gunner against it. It does not target
generic walls or economy buildings, does not suspend Sieger 1, and immediately
returns to direct siege when the seat opens. Existing turret counter-battery,
recall, economy, spawning, and pathfinding are unchanged.

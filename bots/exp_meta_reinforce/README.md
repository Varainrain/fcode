# Meta reinforcement experiment

Parent: frozen `exp_trans_40` (production v8 lineage).

The two opening siegers, t40 economy cutoff, soft recall, home responder,
surgical counter-battery, spawning, and pathfinding are unchanged. The isolated
hypothesis is that ordinary builders freed by the economy transition should join
the existing direct-siege lifecycle instead of exploring. A builder may convert
before t40 only after round 18, after five builders have spawned, and after it
personally sees an enemy core or combat building. The original waller never
converts, preserving one home/economy anchor.

The trigger uses only observable match state. It contains no opponent or map
fingerprints.
